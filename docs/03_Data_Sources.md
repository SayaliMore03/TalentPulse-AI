# Data Sources

## Primary Data Source

### Adzuna Jobs API

Purpose:
Collect real-time job postings for Data Analyst, Business Analyst, BI Analyst, Data Engineer, and Data Scientist roles in India.

Data Collected:
- Job ID
- Job Title
- Company
- Location
- Salary
- Job Description
- Employment Type
- Category
- Date Posted

Reason for Selection:
- Official API
- Real job market data
- Structured JSON format
- Supports automated ETL
- Suitable for analytical reporting

Version:
V1
